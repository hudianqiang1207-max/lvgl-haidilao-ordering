# 海底捞点餐平板使用说明

## 1. 项目简介

本项目是一套基于 C 语言和 LVGL 9 开发的海底捞点餐平板系统，目标运行平台为 GEC6818 ARM 开发板，显示分辨率为 800×480。同时提供 PC 端 SDL2 仿真环境，便于在开发板部署前测试界面和业务。

系统实现菜单分类展示、锅底选择、菜品加购、购物车管理、订单结算、模拟支付、模拟出货以及 TCP 客户端/服务器通信。服务器不可用时，客户端支持本地菜单数据兜底。

> 当前版本的支付和出货属于模拟流程，不是真实微信/支付宝支付，也不直接控制真实机械出货设备。SQLite、MySQL、WebSocket、电子发票等属于后续扩展方向。

## 2. 主要功能

- 菜品按锅底、招牌精选、肉类、海鲜、蔬菜、主食小吃、饮品等分类展示。
- 显示图片、名称、描述、价格和库存状态。
- 库存为 0 时显示“售罄”，并禁止继续加购。
- 支持锅底单选，普通菜品加入购物车、增加、减少、删除和清空。
- 实时计算购物车数量和总价。
- 支持订单确认、微信/支付宝/现金三种模拟支付方式。
- 支付成功后生成订单号并显示出货提示。
- TCP 行协议支持菜单同步、订单、支付、出货和库存测试。

## 3. 运行环境

PC 仿真环境：Linux 或 WSL、GCC、Make、SDL2、FreeType、LVGL 9。

ARM 环境：GEC6818、Linux framebuffer /dev/fb0、触摸输入 /dev/input/event0、800×480 屏幕、simkai.ttf 中文字体，以及可选的 TCP 服务器连接。

## 4. 目录说明

- main_haidilao.c：程序入口和 LVGL 主循环。
- mycode/：显示、触摸、字体、网络等平台代码。
- ui/：LVGL 页面、菜单数据、图片和控件。
- server/：C 语言 TCP 服务器。
- build_arm/：ARM 编译输出。
- Makefile_haidilao：PC SDL2 构建配置。
- Make_arm：ARM 交叉编译、部署配置。
- simkai.ttf：中文字体文件。

## 5. 编译与部署

E 盘目录是资料和交付副本。正式构建使用 WSL 实际构建目录 /home/kongbai/海底捞平板，不要在缺少 lvgl/ 的 E 盘副本直接编译。

PC 编译：

    cd "/home/kongbai/海底捞平板"
    make -f Makefile_haidilao clean
    make -f Makefile_haidilao -j4
    ./haidilao_app

ARM 编译和上传：

    cd "/home/kongbai/海底捞平板"
    make -f Make_arm clean
    make -f Make_arm -j4
    file build_arm/haidilao_arm
    make -f Make_arm send

开发板需要部署 /root/haidi_arm 和 /root/simkai.ttf。不要把 PC SDL 程序上传到 ARM 板，也不要把 ARM 程序当作 PC 程序运行。

## 6. 用户操作流程

1. 启动后进入点餐主界面，查看顶部、分类、菜品和购物车区域。
2. 进入锅底分类，选择一个锅底；锅底为单选项目。
3. 切换肉类、海鲜、蔬菜、主食或饮品，点击加号加入菜品。
4. 在购物车中使用加号或减号调整数量，数量为零时自动移除。
5. 点击结算，检查锅底、菜品、数量、单价和总金额。
6. 选择微信、支付宝或现金，查看模拟支付处理中和支付成功状态。
7. 支付成功后查看订单号和出货提示。
8. 点击返回点餐，开始下一单。

## 7. 网络通信

服务器主要负责菜单和库存、订单校验、订单号生成以及模拟支付和出货。常用命令包括：GET_MENU、ORDER 菜品ID:数量、PAY 订单号 方式、DISPENSE 订单号、STOCK 菜品ID 数量。

## 8. 常见问题

- PC 无法编译：检查构建目录及 SDL2、FreeType、GCC、Make、LVGL 依赖。
- ARM 中文异常：确认 /root/simkai.ttf 存在且字体库架构匹配。
- 菜品售罄：库存为 0，属于正常状态。
- 订单或出货失败：检查服务器、网络地址和端口；断网时可展示本地菜单。
- 修改头文件后未生效：先执行 clean，再完整编译。

## 9. 功能边界

当前已实现并验证菜单展示、锅底选择、购物车、结算、模拟支付、模拟出货、TCP 客户端/服务器、离线菜单兜底和 ARM 部署。真实支付、真实机械出货、数据库持久化、WebSocket 推送和远程管理不应表述为已完成。
