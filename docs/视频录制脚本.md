# 海底捞点餐平板使用视频录制脚本

建议时长：4～6 分钟。使用 GEC6818 开发板或 PC SDL2 仿真窗口录制屏幕和旁白。

## 1. 开场

大家好，我演示的项目是基于 C 语言和 LVGL 开发的海底捞点餐平板系统。项目目标平台是 GEC6818 ARM 开发板，屏幕分辨率为 800×480，同时提供 PC 端 SDL2 仿真环境。系统主要实现菜单浏览、锅底选择、购物车、订单结算、模拟支付和出货状态展示。

## 2. 主界面

当前是系统主界面。顶部显示餐厅和桌号信息，左侧是菜单分类导航，中间是菜品卡片，显示图片、名称、描述、价格和库存状态，右侧是购物车区域，用于显示已选菜品、数量和总金额。

## 3. 锅底和菜单

现在进入锅底分类并选择一个锅底。锅底采用单选逻辑，重新选择会替换之前的选择。接下来浏览肉类、海鲜、蔬菜、主食和饮品等分类。

## 4. 加购和库存

现在选择两种菜品加入购物车。系统加购前会检查库存，正常菜品可以加入，库存为零的菜品显示售罄并禁止继续添加。加购后右侧数量和总金额实时更新。

## 5. 修改购物车

点击购物车加号增加数量，点击减号减少数量，商品总数和总价同步更新，数量为零时菜品被移除。

## 6. 结算

点击结算进入订单确认页面，核对锅底、菜品名称、数量、单价和总金额。确认无误后提交订单，进入支付页面。

## 7. 支付和出货

系统支持微信、支付宝和现金三种支付方式。这里选择微信支付，界面先显示支付处理中，再显示模拟支付成功并生成订单号。支付完成后，客户端向 TCP 服务器发送出货请求。服务器返回成功时显示出货完成，请取餐；如果网络异常或服务器超时，则显示出货故障提示。需要说明的是，当前支付和出货是模拟流程，不代表已经接入真实第三方支付或机械出货设备。

## 8. 客户端/服务器说明

点餐平板作为客户端，服务器通过 TCP 行协议提供菜单同步、库存、订单、支付和出货接口。客户端连接失败时可以使用本地菜单数据兜底，保证基础浏览功能。

## 9. 结尾

点击返回点餐后，系统回到主界面，可以开始下一次点餐。至此，菜单浏览、锅底选择、菜品加购、购物车修改、订单结算、支付和出货状态展示的完整流程演示结束。谢谢大家。

录制注意：点击后停留 1～2 秒；讲解金额、数量、订单号和售罄状态时停在对应位置；不要展示密码、密钥或个人信息；未连接真实设备时明确说明出货环节为模拟通信流程。
