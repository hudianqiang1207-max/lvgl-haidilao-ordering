# 服务端管理台使用说明

## 新增内容

服务端 `server/haidi_server.c` 现在同时提供两种服务：

- `8888`：原有点餐客户端 TCP 行协议；
- `8889`：HTML 管理台和 HTTP/JSON 管理接口。

如果启动端口不是 8888，例如 `./haidi_server 8958`，管理台端口就是 `8959`。

## 打开管理页面

浏览器访问：

```text
http://服务器地址:8889/
```

本机测试：

```text
http://127.0.0.1:8889/
```

页面支持：

- 查看菜单；
- 新增菜品；
- 编辑菜品；
- 删除菜品；
- 修改价格；
- 修改分类；
- 修改库存；
- 查看订单号、金额和状态。

## HTTP 接口

```text
GET    /api/menu       查询菜单
POST   /api/menu       新增菜单
PUT    /api/menu/:id   修改菜单
DELETE /api/menu/:id   删除菜单
GET    /api/orders     查询订单
```

新增/修改 JSON 示例：

```json
{"id":9999,"name":"测试菜","desc":"管理台新增","price":12,"category":6,"stock":7}
```

## 编译运行

```bash
gcc -Wall -O2 -o haidi_server haidi_server.c -lpthread
./haidi_server 8888
```

启动后应看到类似日志：

```text
[server] haidi_server listening on 0.0.0.0:8888 ...
[admin] web console: http://127.0.0.1:8889/
```

## 当前限制

- 数据仍保存在内存中，服务端重启后新增/修改/库存变化会恢复初始值；
- 当前管理台没有登录认证，不建议直接暴露到公网；
- JSON 解析为轻量实现，适合当前固定字段管理，不是完整 JSON 库；
- 菜品名称和描述中包含引号、反斜杠时需要进一步做 JSON 转义；
- 管理台目前服务端默认在 Linux/WSL 编译路径启用，Windows MinGW 仍使用原 TCP 服务编译路径。
