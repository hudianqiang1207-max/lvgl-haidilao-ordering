# 开发板部署清单

## 必传文件

- `haidi_arm`：ARM 可执行程序，对应源码构建输出 `build_arm/haidilao_arm`。
- `simkai.ttf`：中文字体。

## 运行前检查

```bash
ls -l /root/haidi_arm /root/simkai.ttf
ls -l /dev/fb0 /dev/input/event0
```

## 日志判断

- framebuffer 初始化成功：显示设备已打开。
- event0/evdev 初始化成功：触摸输入已打开。
- 中文字体加载成功：字体路径正确。
- 菜单加载完成：本地或服务器菜单已准备。
- 程序无 PID：先查看 `cat /tmp/haidi_arm.log`。
